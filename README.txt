Описание проекта

В рамках учебной практики разработан "RESTful API-сервис", который:
- Принимает название города через GET-параметр
- Запрашивает актуальные данные о погоде через **OpenWeatherMap API**
- Анализирует погоду и формирует **персонализированные рекомендации**:
  - Нужно ли брать зонт?
  - Подходит ли погода для прогулки?
  - Рекомендуемый тип одежды (тёплая / лёгкая)

Проект включает:
- Валидацию входных данных
- Обработку ошибок (город не найден, сетевые сбои)
- Unit-тесты с моками
- Деплой на облачный хостинг

Технологии

- Python 3.12
- Flask — веб-фреймворк
- Requests — HTTP-клиент для взаимодействия с OpenWeatherMap
- unittest + mock — модульное тестирование без интернета
- Render — бесплатный хостинг для деплоя
- GitHub — управление версиями
